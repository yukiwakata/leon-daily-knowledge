怎样用狭缝的收缩或扩张控制黏性指进？

Hele–Shaw 狭缝的间隙沿流向缓慢改变时，毛细压力随位置变化。几何梯度与流速共同决定前沿扰动能否增长。

Control of interfacial instabilities using flow geometry

研究背景

经典认识是：低黏度流体驱替高黏度流体时，均匀 Hele-Shaw cell 中的界面总是不稳定，会形成 viscous fingering；反过来，高黏度流体驱替低黏度流体通常稳定。这个框架的控制空间很窄，因为一旦流体性质确定，稳定性主要由黏度比决定。

作者的问题是：真实狭缝、微流道、肺气道、油藏孔隙和印刷/涂布系统并不均匀，那么能否利用通道形状本身调控界面稳定性？他们选择最简单的几何非均匀性：两块近水平板之间有一个小夹角，使间隙 h(x)=h0+alpha x 沿流向线性变化。

研究方法

实验使用两块厚 plexiglass 板构成宽度 5.1 cm 的 Hele-Shaw cell，通过侧边调平螺丝设置深度梯度，间隙控制精度约 0.1 mm。被驱替流体先从出口填满狭缝，驱替流体从入口以恒压注入。界面演化用背光和数字相机拍摄，随后用 ImageJ 和 MATLAB 追踪界面位置；平均入口速度 U 由被驱替流体占据面积的变化率计算。

理论上，作者使用深度平均 Darcy 定律和带深度变化的质量守恒：

u_j = - h^2/(12 mu_j) grad p_j
div(h u_j) = 0

在小梯度 |alpha| << 1 下，对均匀推进界面作横向小扰动，得到增长率 sigma(k) 的色散关系。关键稳定性判据可写成：

1 - lambda + 2 alpha cos(theta_c) / Ca <= 0

其中 lambda = mu_2/mu_1 是驱替流体相对被驱替流体的黏度比，theta_c 是接触角，Ca = 12 mu_1 U / gamma，alpha 是间隙梯度。临界毛细数：

Ca_c = 2 alpha cos(theta_c) / (lambda - 1)

这说明稳定性不再只由黏度比决定，而由黏度比、润湿性、流速和几何梯度共同决定。

Figure 1 的作用：给出非均匀 Hele-Shaw cell 的几何定义，并用均匀间隙与收缩间隙的空气-矿物油实验做直观对照。均匀间隙中空气形成半宽 finger；收缩间隙 alpha=-2.7e-3 中，同类驱替可得到近似平整界面。这张图是问题转换的入口：不是换流体，而是改几何。

具体结果

结果 1：收缩间隙可以抑制经典不稳定的空气驱替油。

在空气驱替矿物油的系统中，空气黏度远低于油，均匀 Hele-Shaw cell 按经典理论应当不稳定。作者将几何改为沿流向变浅的收缩 cell，使用 h0=1.4 mm、alpha=-2.7e-3、矿物油黏度 25 cP、表面张力 29 mN/m。低毛细数 Ca=6e-3 时，界面保持稳定；较高毛细数 Ca=1.6e-2 时，界面重新失稳。

Figure 2 的作用：展示从稳定到失稳的阈值过程。b 图说明低 Ca 下 fingering 被抑制；c 图说明超过阈值后仍会失稳；d 图把实验点和理论临界 Ca_c=5.4e-3 放在同一稳定性图上，证明式 (3) 能捕捉转变趋势。注意这里不是简单“间隙越窄越稳定”，而是几何项 2 alpha cos(theta_c)/Ca 与黏度比项共同竞争。

结果 2：同一个几何梯度也能触发原本稳定的界面失稳。

作者随后反过来测试一个经典上稳定的系统：湿润硅油驱替非湿润水。均匀 cell 中由于 lambda=4.6>1，高黏度流体驱替低黏度流体应稳定。但在同样收缩的 Hele-Shaw cell 中，低毛细数 Ca=4e-4 时界面沿侧壁发展出 fingering，而较高毛细数 Ca=1.6e-3 时扰动衰减，界面保持平整。

Figure 3 的作用：证明几何梯度不是单向“稳定器”，而是一个可调控项。它可以让原本不稳定的系统稳定，也可以让原本稳定的系统失稳。d 图给出的临界 Ca_c=1.5e-3 与理论判据一致，支撑作者的核心主张：界面行为可由通道几何与流速共同设计。

关键机制

机制链条可以概括为：

  1. 狭缝间隙沿流向变化，使局部渗透率随位置变化，因为 Hele-Shaw 深度平均流动中通量能力随 h^2 改变。
  2. 界面扰动的不同位置会经历不同的局部阻力和毛细压力贡献，几何梯度项进入线性增长率。
  3. 在稳定性判据中，几何项 2 alpha cos(theta_c)/Ca 可以抵消或增强黏度比驱动的失稳项 1-lambda。
  4. 因此，同一对流体在不同流向、不同润湿条件、不同流速下，可能从稳定变为失稳，或从失稳变为稳定。

适用范围与局限

  • 理论采用小梯度假设 |alpha| << 1，且使用深度平均 Darcy 模型；如果间隙变化很陡、三维效应强或局部自由面形变明显，判据需要谨慎使用。
  • 分析假设静态接触角，并未显式处理被驱替流体后方的薄润湿膜；作者认为这些效应解释了理论阈值与实验阈值之间的温和偏差。
